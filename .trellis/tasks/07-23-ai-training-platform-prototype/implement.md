## Validation

```bash
npm run typecheck
npm run test
npm run build
```

启动开发服务后重点验证：

- 工作台导航到所有一级模块。
- 数据集导出三种格式均可提交并产生反馈。
- 矩形、多边形、关键点均能在画布上新建，且对象可选择和删除。
- 四种训练类型均可走完向导；新任务能进入详情。
- 模型版本可分别配置 ONNX、TensorRT、TorchScript 和 OpenVINO 转换。
- 1440x900、1024x768 和 390x844 视口无关键文本、控件和导航重叠。

## Risk And Rollback Points

- 标注指针坐标是交互风险最高的部分：先以单元测试验证归一化和最小尺寸，再接入 SVG UI。
- 跨页面创建状态限制在单个 Context；若行为不稳定，保留预置任务并将提交动作改为导航加反馈。
- 工业图片作为本地资产提交，避免原型依赖外部图片服务。
