# 深度学习训练平台原型 - 技术设计

## Product Shape

原型是一个使用本地模拟数据运行的单页应用。核心信息架构按资产生命周期组织，而不是按技术名词堆叠：

1. 工作台：查看数据、训练、模型和资源概况。
2. 数据中心：管理工业质检数据集、版本、标注进度与导出。
3. 标注工作台：在真实工业图片上创建矩形、多边形和关键点标注。
4. 训练中心：查看任务、创建任务并监控指标、资源和日志。
5. 模型仓库：查看训练产物和版本，并发起模型转换。
6. 转换中心：配置 ONNX、TensorRT、TorchScript、OpenVINO 任务并跟踪产物。

## Architecture

- React + TypeScript + Vite 构建前端应用。
- React Router 管理页面级路由和可分享的 URL。
- Lucide React 提供一致的界面图标。
- 原生 CSS 变量、网格和媒体查询构建设计系统，不引入重量级组件库。
- 应用级 Context 保存模拟任务与 Toast 等跨页面状态；页面局部交互使用组件状态。
- 类型化 mock 模块集中定义数据集、训练任务、模型版本和转换任务，避免页面各自复制不一致的数据。

## Routes And Boundaries

| Route | Responsibility |
|---|---|
| `/` | 工作台与最近活动 |
| `/datasets` | 数据集、版本、标注进度和导出入口 |
| `/annotate/:datasetId` | 标注画布与任务进度 |
| `/training` | 训练任务筛选与状态列表 |
| `/training/new` | 四步训练创建向导 |
| `/training/:jobId` | 指标、资源、日志和训练配置详情 |
| `/models` | 模型版本、评估结果和转换入口 |
| `/conversions` | 转换任务、格式配置和产物下载状态 |

## Shared Data Flow

```text
数据集版本 -> 标注/导出 -> 训练向导 -> 训练任务 -> 模型版本 -> 转换任务 -> 部署产物
```

- “开始训练”携带选中的数据集进入训练向导。
- 向导提交后创建模拟运行任务，并导航到任务详情。
- 模型版本的“转换”操作预选源版本并打开转换配置。
- 导出、训练和转换提交均显示明确 Toast，并在对应列表出现新的模拟记录。
- 页面刷新后不承诺保留新建状态；种子数据始终可复现演示。

## Annotation Interaction

- 使用位图图片作为背景，SVG 作为标注覆盖层。
- 矩形：指针按下、移动、抬起形成归一化矩形；过小标注被忽略。
- 多边形：单击累计顶点，双击或点击“完成”闭合；少于三个点不可提交。
- 关键点：在当前关键点模板中逐点添加，形成带序号的标记。
- 选择：点击已有标注同步右侧对象列表；Delete 按钮删除当前对象。
- 坐标按画布实际尺寸归一化，使响应式缩放不改变标注位置。

## Visual System

- 浅灰页面底色、白色工作区和近黑文字构成长期工作的中性基础。
- 科技蓝用于主要操作、选中态和图表主序列；青绿、橙色、红色分别用于成功、警告和异常。
- 侧栏使用深色中性底而非大面积蓝色，突出产品导航并控制色彩比例。
- 圆角控制在 8px 内；页面区块以边界和间距分组，不使用嵌套卡片或营销式大标题。
- 工业质检图片是标注页第一视觉焦点，彩色覆盖层必须保持清晰可辨。

## Responsive Behavior

- `>= 1200px`：完整侧栏、双栏或三栏工作台、标注左右面板常驻。
- `768px - 1199px`：侧栏收窄，密集表格可横向滚动，标注对象面板缩窄。
- `< 768px`：顶栏和页面内容纵向排列；复杂标注页提示推荐桌面使用，但工具和对象列表仍可访问。

## Compatibility And Rollback

- 目标为现代 Chromium、Firefox 和 Safari；不支持 IE。
- 无后端数据迁移和外部服务副作用。
- 各路由和功能模块保持独立组件边界，若某个高级交互不稳定，可回退为预置数据而不影响其他页面。

## Key Trade-Offs

- 选择 SVG 覆盖层而非 Canvas，便于命中检测、响应式缩放和无障碍标签；大规模标注性能不在原型范围。
- 选择共享 mock 状态而非状态管理库，减少原型依赖，同时维持跨页面故事连续性。
- 训练指标图优先使用轻量 SVG/组件实现，避免为少量固定图表引入大型可视化依赖。
