# 深度学习训练平台原型

## Goal

设计并实现一个面向算法工程师和数据团队的深度学习模型生产工作台原型，让用户能够在同一产品中完成数据集管理与标注、训练任务配置与监控、模型格式转换与产物管理。

## Background

当前仓库没有现成应用代码或前端技术栈。本任务需要从零建立原型的信息架构、视觉体系与关键交互。

## Requirements

- R1：平台提供总览工作台，集中展示数据集、训练任务、模型资产、资源使用情况和近期活动。
- R2：数据标注支持矩形框、多边形和关键点，并提供可理解的标注画布、工具栏、对象列表、类别管理与任务进度。
- R3：数据集支持导出 COCO、VOC 和语义分割格式，并呈现格式选择与导出状态。
- R4：模型训练支持目标检测、语义分割、关键点检测和 SDXL 微调等常见任务族。
- R5：训练配置应覆盖模型选择、数据集与版本、核心超参数、计算资源、评估与保存策略。
- R6：训练任务提供可扫描的队列/列表和单任务监控视图，展示状态、进度、指标、资源和日志等关键信息。
- R7：模型转换支持 ONNX、TensorRT、TorchScript 和 OpenVINO，并表达各格式的适用硬件、精度与配置差异。
- R8：模型资产和转换任务具备来源、版本、格式、状态、大小和创建时间等可追溯信息。
- R9：原型覆盖数据准备、训练、模型资产、格式转换之间的端到端导航，避免三个模块成为互不关联的孤立页面。
- R10：界面使用中文，定位为安静、专业、信息密度适中的桌面端工作台，并具备基本响应式能力。
- R11：模拟业务以工业质检为主线：零件/器件用于目标检测，划痕与缺陷区域用于多边形及语义分割，装配定位点用于关键点；SDXL 体现合成缺陷样本生成或微调任务。
- R12：标注画布支持基础真实绘制：拖拽创建矩形框、逐点创建多边形、点击添加关键点，以及选中和删除标注。
- R13：训练任务创建采用四步向导：任务类型、数据与模型、参数与资源、确认启动；高级参数以可展开区域提供。
- R14：视觉采用浅色专业工作台，以科技蓝为主操作色，使用独立的成功、告警和错误色表达状态；避免单一蓝色铺满界面。

## Constraints

- 当前仓库无可复用业务代码。
- 实现范围为高保真、可点击的交互式前端原型，使用本地模拟数据和前端状态表达完整流程。
- 不实现真实后端、持久化、文件上传、训练执行或模型转换执行。
- 原型默认用户已经登录并进入单一工作空间，不设计登录、组织、成员和权限管理。
- 首版以关键工作流的可演示性和产品表达为主，不以生产级训练基础设施为目标。
- 桌面端为主要演示环境；窄屏需要保持可导航、可阅读且无控件重叠，但复杂标注优先保证桌面体验。

## Acceptance Criteria

- [x] AC1：用户可以从总览进入数据集、标注、训练、模型和转换等关键模块。
- [x] AC2：标注工作台可以使用矩形框、多边形和关键点工具创建真实标注，并能选中、查看和删除标注对象。
- [x] AC3：数据集导出流程可以选择 COCO、VOC 或语义分割格式并提交模拟导出任务。
- [x] AC4：用户可以创建四类训练任务之一，填写核心配置并启动模拟训练。
- [x] AC5：训练列表和详情能表达排队、运行、完成或失败等状态及关键指标。
- [x] AC6：用户可以从模型版本创建 ONNX、TensorRT、TorchScript 或 OpenVINO 转换任务。
- [x] AC7：关键交互有可见反馈，页面在常见桌面与窄屏视口下不出现文本或控件重叠。
- [x] AC8：项目提供明确的本地运行方式，并通过构建、静态检查和关键页面浏览验证。

## Out Of Scope

- 生产级 GPU 调度、分布式训练、真实模型转换引擎和云资源编排。
- 多租户计费、细粒度 RBAC、SSO、审计合规和线上告警体系。
- 完整实现各标注格式的真实导入导出与大文件传输。
- 登录、组织切换、成员邀请与权限配置。
- 复杂顶点编辑、画布旋转、高级快捷键体系、多人实时协作与冲突合并。
