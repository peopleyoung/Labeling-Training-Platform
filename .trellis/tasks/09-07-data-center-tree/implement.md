## Phase 1: Contract and Migration

- 在 `shared/contracts.ts`、`shared/schemas.ts` 增加任务大类、业务任务、数据中心树和筛选参数类型。
- 新增数据库迁移，创建全局任务目录表，写入五个大类，不创建业务任务。
- 为数据集增加 `task_type_id`、`created_at`、`approved_at`，建立索引并移除旧类型约束。
- 编写一次性全量数据清理脚本，调用现有删除/制品清理能力，删除当前全部数据集后再完成非空约束迁移；执行结果写审计。

## Phase 2: Repository and API

- 在 `server/repository.ts` 增加目录 CRUD、排序、停用、关联计数、数据集改绑和数据中心聚合查询。
- 在 `server/api.ts` 增加管理员目录接口、数据中心树接口和数据集任务绑定接口。
- 修改数据集创建校验：必须传入启用的 `taskTypeId`；更新 `可训练` 状态时写入 `approved_at`。
- 数据中心查询使用全局范围，固定过滤 `可训练` 和已绑定任务类型，按创建时间、类别和业务任务筛选。
- 写入目录变更、数据集改绑和批量清理审计事件。
