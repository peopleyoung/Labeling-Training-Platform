# 标注工作台跨帧追踪与参考平台功能对齐

## Goal

让标注员和审核员在视频任务中能够创建、编辑并保存跨帧对象轨迹，同时让标注工作台已有按钮的实际行为与参考平台对应控件一致，避免出现按钮存在但行为不一致或无效的情况。

## Background

当前工作台已经支持光标、移动画布、旋转、缩放、矩形、多边形、折线、点、立方体、保存、撤销、重做、提交和审核等基础能力。参考平台实际工作台还包含跳帧控件、标签工具、工作区控件、合并/分组/分割轨迹等控件；矩形、多边形、折线、点和长方体的绘制配置中均提供“绘制”和“追踪”两种操作。

当前帧切换和播放只切换图像，不创建轨迹数据；`Ctrl+B` 仅把一个对象一次性复制到下一帧。共享契约虽已预留 `trackId`、`keyframe`、`provenance` 字段，但当前前后端没有轨迹生成、插值或轨迹级保存逻辑。

已确认的产品范围：支持视频上传；支持目标检测、实例/语义分割、关键点；立方体使用参考平台的八点交互；审核员可以修改后保存并记录审核员修改与标注员标注的归属；不实现合并和分割算法，不保留新的标注版本，只记录最终结果和审核员修改差异。

## Requirements

### R1. 跨帧轨迹

- 在每个支持绘制的工具配置中提供与参考平台一致的“绘制”和“追踪”入口；选择“追踪”后进入轨迹标注模式，而不是普通单帧绘制模式。
- 在视频任务中可将当前对象创建为轨迹，并显示明确的轨迹状态、轨迹标识和关键帧状态。轨迹模式使用参考平台的关键帧/中间帧语义，不将普通播放或单次复制伪装成追踪。
- 轨迹应能关联同一对象在多个帧中的几何数据，覆盖当前支持的矩形、四点多边形/分割、关键点和八点立方体；多边形、折线、立方体和骨架类几何仅在前后关键帧拓扑兼容时进行插值，不兼容时必须提示并允许回退到手动关键帧。
- 支持在当前帧和其他帧编辑轨迹关键帧，重新加载、切换帧、刷新页面后轨迹关系和最终几何结果保持一致。
- 中间帧的轨迹结果应可被查看、编辑和保存，并与标注员/审核员的归属信息区分。
- 选中轨迹时支持跳转到上一关键帧/下一关键帧，并支持参考平台语义的跨帧复制操作；跨帧复制必须保留其他帧已有对象，不能覆盖无关标注。
- 轨迹保存必须复用现有标注保存/审核权限，不能绕过任务段最后一帧提交限制。

### R2. 工具栏和操作按钮对齐

- 矩形、多边形、折线、点、立方体等核心绘制按钮继续保持连续绘制模式，完成一个对象后仍可使用当前工具绘制下一个对象。
- 保存、撤销、重做、提交、通过、驳回的按钮行为必须与当前角色和参考平台工作流一致，并给出成功或失败反馈。
- “标记为错”必须是独立的错误标记行为，不能删除选中对象。
- 快捷键弹窗中列出的快捷键必须都可执行；不存在的合并、分割能力不能伪装成已实现快捷键。`M` 的移动画布快捷键与其他快捷键不得冲突。
- 标签工具必须执行标签标注对应行为，不得仅切换右侧标签列表；设置、标注信息、全屏、用户菜单、返回数据中心等按钮必须保持可用。
- 帧控制应覆盖参考平台的首帧、上一帧、播放/暂停、下一帧、末帧和跳帧语义；选中轨迹时还应支持关键帧前后导航。播放过程中不能触发重复保存或破坏当前未保存草稿。
- 已明确暂不实现的合并、分组、分割和调整画布，不在本次伪造为可用功能；若保留入口必须禁用并明确提示。

### R3. 归属和统计

- 轨迹产生的标注结果继续区分标注员创建/修改和审核员修改。
- 统计标注量时，轨迹在各帧产生的对象结果应可按标注员归属统计，审核员修改不计入标注员原始标注量。
- 不创建新的用户可见标注版本；保存最终结果并记录审核员修改差异。

## Acceptance Criteria

- [ ] 标注员在视频中从任一绘制工具配置选择“追踪”并创建对象轨迹，切换到轨迹覆盖的帧时能看到对应对象；刷新后轨迹关系和几何结果仍存在。
- [ ] 在轨迹首尾关键帧修改矩形、多边形/分割、折线、关键点或八点立方体，中间帧显示确定性的插值结果；中间帧可继续编辑并保存。
- [ ] 轨迹中的对象具有可识别的 `trackId`/关键帧状态，接口保存和重新加载不会丢失关联。
- [ ] 审核员修改轨迹后，最终结果可保存，且审核员修改与标注员标注的归属和统计数据保持区分。
- [ ] 核心绘制工具可以连续创建多个对象；矩形保存、提交、播放、帧切换和未保存草稿的行为均有自动化测试覆盖。
- [ ] 点击“标记为错”不会删除对象，并能在对象/Issues 相关区域看到错误状态或后续处理状态。
- [ ] 快捷键弹窗列出的可用快捷键均有对应实现；未实现的合并/分割不再显示为可用快捷键。
- [ ] 参考平台实际存在的首帧、上一帧、播放/暂停、下一帧、末帧和跳帧操作在当前平台有等价且可用的按钮；选择绘制工具后可看到“绘制/追踪”入口；设置、标签工具、工作区、退出登录和返回数据中心按钮均可操作。
- [ ] `npm run typecheck`、`npm run typecheck:server`、相关 Vitest 测试和构建通过。

## Scope

### In scope

- 跨帧轨迹的数据结构、保存/读取接口、前端轨迹交互、关键帧和中间帧几何处理。
- 参考平台工作台中当前已有按钮的真实行为补齐和不一致修正。
- 相关单元测试、组件测试、接口测试和必要的用户流程测试。

### Out of scope

- 基于视觉模型的自动目标跟踪、检测模型推理或跟踪失败自动修复。
- 合并、分组、分割轨迹算法。
- 新的用户可见标注版本体系。
- 与本任务无关的数据中心、训练、转换和部署功能改造。
