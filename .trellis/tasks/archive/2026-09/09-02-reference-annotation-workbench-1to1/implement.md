# 执行计划

1. 采集参考平台工作台 DOM、计算样式、快捷键和事件证据，形成可核对清单。
2. 抽离当前项目 Job 数据加载、权限和保存业务，建立新工作台输入输出接口。
3. 实现参考平台布局、固定尺寸、状态栏、帧导航和面板结构。
4. 实现工具状态机、几何渲染、控制点命中、选择/移动/缩放和多点绘制。
5. 实现快捷键优先级、保存队列、冲突处理和视口稳定性。
6. 逐项补充工具、快捷键、并发保存和 Job 权限回归测试。
7. 运行前端/后端类型检查、全量测试、构建和可运行端到端验收。

## 变更边界

- 必须修改：标注页面、工作台组件、标注几何/快捷键/序列化适配器、工作台样式和相关测试。
- 尽量不修改：后端 Job/审核/训练/导出接口；只有发现契约无法承载参考形状时才在共享适配边界增加字段。
- 明确不做：不再对旧 `AnnotationPage` 继续增加局部工具，不凭猜测扩展未验证的参考平台行为。
