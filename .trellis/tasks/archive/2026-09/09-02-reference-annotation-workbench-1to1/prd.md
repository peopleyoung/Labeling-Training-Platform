# 1:1 重做参考平台标注工作台

## Goal

在当前项目中重新实现参考平台的 Job 标注页面。用户在相同任务状态和相同媒体下，应看到并操作同一套工作台结构、快捷键、帧导航、绘制手势、几何样式和对象操作；当前项目的权限、Job、审核、标注持久化、训练和导出能力继续作为业务后端。

## Confirmed Reference Facts

- 参考平台工作台路径为 `/subapp/jobs/{taskId}/{jobId}`，标题为“计算机视觉标注工具”。
- 页面包含顶部操作区、帧导航、左侧图像/工具区域、中央画布和右侧对象/标签/Issues 区域。
- 已确认可见绘制控制包括光标、画布旋转、矩形、多边形、折线、点和立方体；对象侧支持顺序、锁定、遮挡、隐藏、置顶和外观设置。
- 参考平台标注接口使用 CVAT 风格的 `tags`、`shapes`、`tracks` 分层；已采样形状使用图像像素坐标、`frame`、`label_id`、`points`、`occluded`、`z_order` 等字段。
- 参考平台进入任务后会存在自动分配请求；当前项目采用显式、可审计的 Job 领取，不复制不可控的隐式写入。

## Requirements

### R1. 工作台整体结构

- 用独立的 `ReferenceAnnotationWorkbench` 替换当前 `AnnotationPage` 的旧编辑器实现，不继续在旧组件上局部叠加工具。
- 复刻参考平台的顶栏、状态信息、帧导航、左侧控制区、中央画布、右侧对象区和底部/侧边辅助区；桌面端优先与参考平台尺寸、间距、颜色和边框一致。
- 页面只允许在当前 Job 的 Segment 范围内浏览帧；不能跨 Job 读取或修改图片。

### R2. 操作与快捷键

- 逐项建立参考平台实际可用的快捷键映射和冲突优先级，包括保存、撤销、重做、删除、复制/粘贴、首帧、上一帧、下一帧、末帧、工具切换、完成/取消绘制、缩放、旋转、全屏和面板操作。
- 快捷键在输入框、下拉框、弹窗和文本编辑状态下不得抢占浏览器/控件行为。
- 上一张/下一张切换必须处理未完成绘制、正在保存、冲突和审核只读状态，行为与参考平台一致；不允许因状态刷新导致画布跳动。

### R3. 标注工具与手势

- 矩形、 多边形、折线、点、立方体按参考平台工具状态、鼠标按钮、悬停反馈、完成手势和取消手势实现。
- 多边形/折线采用参考平台连续点选方式；双击完成时不得产生重复末点，右键/Escape 取消，完成后立即进入参考平台一致的选择状态。
- 每类 Shape 的控制点、顶点、边线、填充透明度、描边宽度、选中态、悬停态、锁定态和不可编辑态按参考平台几何比例实现，不能使用当前页面的固定近似尺寸。
- 对象移动、顶点编辑、框体缩放、锁定、隐藏、遮挡、置顶、复制和删除按参考平台状态变化实现。
- 当前项目特有的 Track、SDXL Caption 等业务扩展不得改变参考平台主工具的视觉和交互；应放入与参考平台一致的对象属性/业务面板中。

### R4. 保存与状态一致性

- 自动保存必须以不可变编辑快照提交；请求期间继续编辑不得被旧响应覆盖。
- 保存状态变化不得改变画布容器尺寸、滚动位置或帧导航布局。
- 保存成功、冲突、失败、审核提交和返工必须通过稳定状态栏反馈，不得用会推动工作台布局的临时元素。
- 冲突时保留本地草稿，并提供加载服务器版本和保留本地覆盖两个明确动作。

### R5. 业务接入

- 当前项目的认证、角色权限、Job 领取/提交、审核通过/驳回、返工、审计、训练快照和导出接口保持不变。
- 标注数据通过当前项目统一 `AnnotationDocument`/revision 契约保存；需要 CVAT 形状时在序列化边界完成转换，不把参考平台临时 JSON 直接扩散到业务层。

## Acceptance Criteria

- [ ] 参考平台和当前项目在同一桌面视口下，工作台主要区域、工具顺序、状态栏和帧导航结构逐项对齐。
- [ ] 每个已确认工具都有独立的交互测试：工具激活、绘制、完成、取消、选中、编辑、删除和只读状态。
- [ ] 快捷键测试覆盖保存、撤销/重做、删除、复制/粘贴、首尾帧、上一张/下一张、工具切换、完成和取消，并验证输入控件不被抢占。
- [ ] 自动保存并发回归测试验证：请求未返回期间新增/修改标注，响应返回后本地新修改仍存在且会继续保存。
- [ ] 连续切换帧和图片加载不会改变画布外框尺寸、滚动位置和顶部/底部操作区布局。
- [ ] 多边形和折线双击完成后顶点数量准确，不出现重复末点；右键/Escape 取消后无残留草稿。
- [ ] Job 范围、标注员权限、审核员只读/编辑权限、提交/返工、训练快照和导出相关现有测试全部通过。
- [ ] `npm run typecheck`、`npm run typecheck:server`、`npm test`、`npm run build` 和可运行的端到端验收通过。

## Out of Scope

- 不修改当前项目训练、导出、模型和用户管理业务规则。
- 不复制参考平台的隐式自动分配副作用；Job 领取仍由当前项目显式接口完成。
- 未通过参考平台实测或未能取得样例数据证明的高级工具行为，不允许凭猜测实现；需要先补齐证据或标记为明确后续项。
